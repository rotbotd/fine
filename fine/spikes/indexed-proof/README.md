# Native indexed-proof boundary probe

This probe answers one representation question before Fine grows surface syntax
for indexed proof families.  It runs three small solver problems:

1. `native-step.smt2` defines `Tm` as a native datatype and `Step : Tm × Tm`
   as a least Horn relation.  A constructor-generated path is reachable and a
   pair generated by no constructor is not.  There is neither a universal term
   universe nor a runtime/witness sort.
2. `intro-axioms-admit-junk.smt2` gives an ordinary Bool function only the
   constructor introduction implications.  Z3 accepts a non-constructor pair,
   demonstrating why this familiar encoding is too weak for inversion or
   induction.
3. `cofinite-horn-is-existential.smt2` puts a fresh-name variable only in a Horn
   body.  The head is derived from one working name even while another fresh
   name witnesses failure.  This is existential search, not the cofinite
   premise `forall x, fresh(x, L) -> ...`.

Run the complete countertest with:

```sh
nix run .
```

The accepted compiler boundary is therefore split.  Ordinary strictly-positive
recursive premises may lower to least native-sort relations.  A universally
quantified constructor premise remains explicit in Fine's indexed-family IR;
the compiler must eventually elaborate it to an arbitrary-fresh branch together
with the freshness/equivariance obligation that makes one representative sound.
It must not erase the quantifier by placing its variable in an ordinary Horn
body.

The next source slice is deliberately smaller than locally nameless STLC: add
one proof-only indexed family over existing native datatypes with base and
first-order recursive constructors, expose constructor/inversion evidence in
Rainfall, and reject universal constructor premises with the precise message
that this probe justifies.  The following slice adds the arbitrary-fresh
elaboration; only then can the locally nameless `Step` fixture be admitted.

## Retained equivariance null

`open-equivariance-timeout.fine` is the first direct formulation of the missing
name-choice theorem for the executable locally nameless operations. It defines
de Bruijn opening, a maximum-free-name cutoff, and free-name renaming, then asks
Fine's weak direct-subterm induction to prove

```
rename(open_at(term, depth, fresh), fresh, other)
  == open_at(term, depth, other)
```

when both names lie above the computed cutoff. The query exceeded twenty
seconds with no answer:

```sh
timeout 20 nix run . -- run \
  fine/spikes/indexed-proof/open-equivariance-timeout.fine
# exit 124
```

This file is not a fixture and receives no extra fuel. The ordinary induction
translation quantifies one direct subterm but gives Z3 no constructor-owned
case evidence for the two nested recursive functions. The locally nameless
opening fixture therefore establishes actual opening, support computation,
fresh availability, and arbitrary-branch ownership, but not this equivariance
theorem.
