Fine

A browser build of Fine. Proof evidence remains virtual; Rainfall is the trace produced by the same executable.

language reference

Int and Bool are runtime types. Id(A, left, right) is proof-only: Fine can search for its evidence, but a running program cannot inspect it.

form what Fine checks smallest example
runtime binding The expression has the declared runtime type. let n: Int = 7;
value function The body has the result type and satisfies every ensures clause. function keep(x: Int) -> Int
ensures { result == x; }
{ x }
identity evidence refl(value) is accepted only when both endpoints are the exact same value. proof p: Id(Int, n, n) = refl(n);
needed evidence The function is checked with the identity available; each call must supply matching local evidence. needs [same: Id(Int, left, right)]
explicit evidence The named local proof exactly matches the callee's instantiated need. replace(x, y) using [same = p]
proof hole ? searches typed local evidence, refl, then applicable proof functions. proof q: Id(Int, n, n) = ?;
proof function Its result follows from its value indices and needed evidence; it cannot be called as runtime code. proof function symm(left: Bool, right: Bool)
needs [p: Id(Bool, left, right)]
-> Id(Bool, right, left);
executable check A run block is closed over runtime values and every assertion must hold. run demo {
  let n: Int = 7;
  assert n == 7;
}
