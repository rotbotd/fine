Fine

A browser build of Fine. Proof evidence remains virtual; Rainfall is the trace produced by the same executable.

language reference

Int, Bool, and declared enums are runtime types. Id(A, left, right) and declared proof inductive families have no runtime representation. Fine may reduce a proof-family match while compiling only when its solver context leaves one constructor and every value field used by the arm is already determined by a runtime index; no proof tag or field is loaded by the running program. Top-level declarations may be interleaved. A definition-only document needs no run; at most one named run block contains executable checks. The examples below are accepted excerpts from checked fixtures, not a second speculative grammar.

structural proof induction inducts(evidence) exposes the function to its own proof body only as an induction hypothesis. Each self-call must consume its exact recursive field; constructors with two fields retain two distinct IH edges. No runtime call is created. proof function plus_shift(a: Nat, b: Nat, c: Nat)
  takes [evidence: Plus(a, b, c)]
  inducts(evidence)
  -> Plus(a, succ(b), succ(c)) {
  match evidence {
    plus_zero(base) => plus_zero(succ(base)),
    plus_succ(pa, pb, pc) =>
      plus_succ(pa, succ(pb), succ(pc))
        using [rest = plus_shift(pa, pb, pc)],
  }
}
