Fine

A browser build of Fine. Proof evidence remains virtual; Rainfall is the trace produced by the same executable.

language reference

Int, Bool, and declared enums are runtime types. Id(A, left, right) and declared proof inductive families are proof-only: Fine retains their source evidence, but a running program cannot inspect it. Declarations appear in this order: enums, proof inductives, functions, then one run.

form what Fine checks smallest example
runtime binding The expression has the declared runtime type. let n: Int = 7;
runtime enum Each payload is a runtime type. A field may recursively use the enum being declared. enum Nat {
  zero,
  succ(Nat),
}
runtime constructor Every payload has the constructor's declared type. let one: Nat = succ(zero);
runtime match Every constructor appears exactly once, pattern arities agree, and all arms return one runtime type. match n {
  zero => zero,
  succ(previous) => previous,
}
value function The body has the result type and satisfies every ensures clause. function keep(x: Int) -> Int
ensures { result == x; }

identity evidence refl(value) is accepted only when both endpoints are the exact same value. proof p: Id(Int, n, n) = refl(n);
static evidence input The function is checked with the identity available; each call must supply matching local evidence. takes [same: Id(Int, left, right)]
explicit evidence The named local proof exactly matches the callee's instantiated static input. replace(x, y) using [same = p]
proof hole ? searches typed local evidence, refl, then applicable proof functions. proof q: Id(Int, n, n) = ?;
partial proof checkpoint fine checkpoint --proof-budget n writes the best typed partial term as ordinary Fine. Checked subtrees remain syntax; unresolved leaves remain ? and are never absorbed as evidence. Running checkpoint again resumes at those nested holes. trans[left, middle, right](p, ?)
indexed proof hole Deterministic search admits exact local family evidence and structurally decreasing IH applications. Wrong indices and the root are absent before enumeration; constructor and Z3-model search are not yet admitted. even_next[previous](prior) =>
  rebuilt_next[previous](?)
// ? ← rebuild[previous](prior)
proof function Its result follows from its value indices and taken evidence; it cannot be called as runtime code. proof function symm(left: Bool, right: Bool)
takes [p: Id(Bool, left, right)]
-> Id(Bool, right, left);
indexed proof family Its indices are runtime values, but its constructors and evidence exist only in the static proof layer. proof inductive Even(value: Nat) {
  even_zero() -> Even(zero);
  even_next(previous: Nat)
    takes [prior: Even(previous)]
    -> Even(succ(succ(previous)));
}
indexed constructor evidence Square brackets instantiate static value parameters; parentheses supply exact virtual proof fields. proof two: Even(succ(succ(zero)))
  = even_next[zero](zero_even);
indexed proof match Constructor results refine symbolic indices before arm checking. Brackets bind static values, parentheses bind proof fields, and only reachable constructors are required. match evidence {
  even_zero() => shape_zero[value](refl(value)),
  even_next[previous](prior) =>
    shape_next[value, previous](refl(value), prior),
}
structural proof induction inducts(evidence) exposes the function to its own proof body only as an induction hypothesis. Each self-call must consume its exact recursive field; constructors with two fields retain two distinct IH edges. No runtime call is created. proof function rebuild(value: Nat)
  takes [evidence: Even(value)]
  inducts(evidence)
  -> Rebuilt(value) {
  match evidence {
    even_zero() => rebuilt_zero(),
    even_next[previous](prior) =>
      rebuilt_next[previous](rebuild[previous](prior)),
  }
}
empty proof match Evidence with no reachable constructor eliminates into any proof type with zero arms. match impossible { }
executable check A run block is closed over runtime values and every assertion must hold. run demo {
  let n: Int = 7;
  assert n == 7;
}
